# Biblioteca de Camadas (L1)

Camadas são opcionais. O usuário escolhe quais usar.

## Famílias planejadas

- Cabeçalho (institucional, editorial, minimalista)
- Elemento principal (tipográfico, imagem, gráfico)
- Conteúdo (uma coluna, cards, checklist)
- Destaque (citação, dado, alerta)
- Rodapé (compacto, referências)

Cada camada deve referenciar os tokens oficiais e ter `optional: true` por padrão, salvo exceção explícita.
